# 产品设计

## 目标用户

- 本机开发者
- 使用 Claude Code 写代码、改代码、查上下文
- 希望切到本地模型，降低外部依赖和成本

## 核心诉求

1. 一个入口
2. 多个后端
3. 逻辑模型名不暴露实现细节
4. 保持 Claude Code 使用方式不变

## 设计判断

当前阶段的产品设计已经冻结，后续只做实现，不再改产品边界。

## 产品形态

- 控制面：本地 Web UI，用来配模型、发 key、看状态、管更新
- 数据面：兼容接口网关，只负责接请求、路由、转发、流式返回
- 交付单元：macOS 上统一打包，不把 UI 和网关拆成两个独立升级体

## MVP 范围

- 一个网关域名
- 一个逻辑模型名到 provider/model 的映射层
- Claude Code 可直接使用的消息生成接口
- 基础 token 计数接口
- 本地开发场景下的健康检查和最小观测

## 体验原则

- 默认能用
- 切换后端无感
- 问题可观测
- 慢模型不被网关进一步拖慢

## 完成标准

- 产品目标、用户、边界、体验和交付形态已经统一
- 用户只需要配置一个入口地址
- 逻辑模型名不会暴露真实 provider 细节
- provider 切换不改变上层使用方式
- 失败时能快速定位到路由、适配器还是上游模型
- 关键路径有 benchmark 和最小测试覆盖

## 非目标

- 不做网页控制台
- 不做模型训练和微调管理
- 不做复杂的多租户系统
- 不做长链路业务编排
